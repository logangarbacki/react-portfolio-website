— Abstract —

The author is a self-taught QA Automation Engineer with a full-stack perspective on quality. He builds Selenium frameworks in C# that hold up under sprint pressure, and writes the React applications they're aimed at. At PrintScan he helped develop a framework that reduced manual regression testing by over forty percent. What follows is a catalog of selected work, capabilities, and prior engagements — recorded here in lieu of a more conventional résumé.

I — Notes on the author

Quality first,
always.

I am, by trade and disposition, a tester. I learned C# before I learned React, which is to say I learned how to break software before I learned how to build it.1 The result is a particular point of view — an automation engineer who can read a stack trace as comfortably as a stylesheet, and who treats every front-end as a system that owes its users a working state.

At PrintScan I worked alongside a senior developer to architect a regression framework in C# that reduced manual sprint testing by more than forty percent.2 I'm currently extending that posture into full-stack TypeScript work — Next.js, Supabase, and serverless orchestration of language models — because I believe the best automation engineers know exactly how the application is constructed. So I keep building applications.

Figure 2. AgencyBuilder · 2026 — present

A lead-generation platform (in beta).

Next.js 16 · TypeScript · Tailwind v4 · Supabase · OpenRouter · Stripe · Vercel

A full-stack TypeScript application for local-business agencies, built on the Next.js App Router with serverless route handlers in place of a separate backend service.
